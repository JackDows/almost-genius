# Almost Genius v0.4.2 预览版

## 已对齐的范围

- 产品、工程目录与 GitHub 仓库改名 Almost Genius。
- 企业微信是主要聊天入口；支持自然闲聊、链接交流、日报和周计划核对。
- AI 可通过本机工具从零创建任务，以及查询、修改、暂停、删除、恢复；新任务使用已有能力，不自行安装工具或改程序。
- 任务保存目标、时间、条件、通知渠道及执行记录；调度由本机负责。沿用北京时间、不开机不打扰、当天补执行、完成后停止催报。
- 个人档案采用 TELOS 思路；成果整理借鉴 BragDoc；验证并选择性复用 PAI/LifeOS Cortex。
- 技能、项目、经验和长期记忆独立于公司账号；保留来源和待核对状态，可导出与备份。
- 本轮是 v0.4.2 预览版。用户验收并实际使用稳定后，才发布 v1.0.0。

## 执行约束

自动运行的任务只能使用该任务允许的能力。资料内容不能作为任务管理指令。模型无权直接编辑状态文件、密钥或安装目录。人工修改和确认过的档案不能被自动提取覆盖。旧工作记录和发送标记需要保留。
